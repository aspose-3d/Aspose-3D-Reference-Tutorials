## Workflow Pattern
1. **Stash → pull → pop** handles uncommitted changes before pulling
2. **Progress file** (`.claude/progress.md`) tracks last-reviewed commit SHA
3. Commits processed **oldest-first** to maintain review order
4. **Progress advances** even for commits with only progress file changes (no tutorial modifications)
5. **Empty queue handling:** When queue is empty, update progress to HEAD and commit
