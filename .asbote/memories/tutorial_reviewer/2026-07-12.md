# Tutorial Reviewer - Daily Workflow Summary

## Workflow Pattern
1. **Start of session**: Pull latest commits with rebase, restore from stash if needed
2. **Check progress**: Read `.claude/progress.md` to find last-reviewed commit
3. **Get queue**: List commits after last-reviewed using `git log --reverse`
4. **Process each commit**:
   - List changed English tutorial files (grep for `_index.md`)
   - For each file, extract code blocks (Java/C#)
   - Verify snippets compile with `aspose-cli verify <lang> 26.6.0`
   - Fix any errors using `aspose-cli api` to find correct signatures
   - Update progress after each commit

## Key Decisions
- Use **26.6.0** as the pinned version for all verification
- Process commits **oldest first** to maintain order
- Update `.claude/progress.md` after **each commit** is fully reviewed
- Commit and push only when queue is **drained to HEAD**
- Use stash→pull→pop pattern when uncommitted changes block pull

## Technical Details
- Java verification: `aspose-cli verify java 26.6.0 <code-file>`
- .NET verification: `aspose-cli verify csharp 26.6.0 <code-file>`
- API lookup: `aspose-cli api show/search/list` for signatures
- Code blocks are marked with `// ExStart:<tag>` ... `// ExEnd:<tag>`
