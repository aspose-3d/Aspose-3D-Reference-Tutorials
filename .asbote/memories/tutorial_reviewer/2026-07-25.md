## Key API Knowledge (Aspose.3D 26.6.0)

- `Common.createMeshUsingPolygonBuilder()` **does not exist** - need to create meshes manually using `Mesh.addControlPoint()` and `Mesh.createPolygon()`
- `FVector4` is the correct type for normal vector data, not `Vector4`
- `Mesh.createElement(VertexElementType.NORMAL, MappingMode, ReferenceMode)` returns `VertexElement`
- `VertexElementNormal.setData()` accepts `FVector4[]`, `FVector3[]`, or `FVector2[]`
