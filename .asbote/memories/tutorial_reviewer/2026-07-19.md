# Daily Tutorial Review Workflow Established

## System Configuration
- **Task ID:** `bb2c22d6-1081-4d86-a96b-45a052cfe9dd`
- **Schedule:** Daily at 6:00 AM (Asia/Shanghai timezone)
- **Verification Tool:** `aspose-cli` with version **26.6.0** (both Java and .NET)
- **Target Repository:** `aspose-3d/Aspose-3D-Reference-Tutorials`

## Workflow Pattern

### Morning Routine (6:00 AM)
1. **Stash** any uncommitted changes
2. **Pull --rebase** to sync with remote
3. **Pop** stashed changes if any
4. **Read** `.claude/progress.md` to get last-reviewed commit SHA
5. **List commits** after the last-reviewed SHA
6. For each commit:
   - Check if it modified English tutorial files (`3d/english/(java|net)/.*_index\.md`)
   - If no tutorial files modified (commonly only progress.md changes), advance queue
   - If tutorial files modified, review and verify code snippets
7. **Update** `.claude/progress.md` after each commit is fully processed
8. When queue is empty: **stage**, **commit**, **push**

## Key Decisions

### Progress Tracking
- Single source of truth: `.claude/progress.md` records `last-reviewed: <sha>`
- Commit progress after each commit (not batched)
- Only commits with tutorial file changes need review; progress-only commits advance queue

### Verification Process
- Extract code blocks from `_index.md` files (Java and C#)
- Merge consecutive blocks with matching `// ExStart:<tag>` / `// ExEnd:<tag>` markers
- Use `aspose-cli verify java 26.6.0` or `aspose-cli verify csharp 26.6.0`
- Confirm API usage with `aspose-cli api show` or `aspose-cli api search` if errors occur

### Fix Propagation
- Fix English source files first (authoritative)
- Propagate corrected code verbatim to all translated language folders
- Don't re-verify translated snippets
- Don't modify translated prose or front matter
