# Kurangi ukuran file 3D – kompres adegan dengan Aspose.3D untuk Java

Jika Anda mengirimkan aset 3D melalui web, email, atau menyimpannya di bucket cloud, ukuran file yang besar dapat dengan cepat menjadi bottleneck. Dalam tutorial ini Anda akan belajar **cara mengurangi ukuran file 3d** dengan mengompres adegan 3D menggunakan Aspose.3D untuk Java. Kami akan memandu pembuatan adegan, menambahkan objek, menyesuaikan transformasi, dan akhirnya menyimpan adegan dengan opsi kompresi yang menjaga kualitas visual tetap utuh sambil mengecilkan file secara dramatis. **Tutorial Aspose 3D** langkah‑demi‑langkah ini menunjukkan secara tepat **cara mengompres 3d** aset untuk pengiriman lebih cepat dan biaya penyimpanan lebih rendah.

## Jawaban Cepat
- **Apa arti “reduce 3d file size”?** Itu berarti menerapkan teknik kompresi pada file 3‑D sehingga ukuran di disk menjadi lebih kecil tanpa kehilangan geometri atau fidelitas tekstur.  
- **Format apa yang mendukung kompresi di Aspose.3D?** Format AMF (Additive Manufacturing File), menggunakan `AmfSaveOptions`.  
- **Apakah saya memerlukan lisensi untuk mengompres?** Versi percobaan dapat digunakan untuk pengembangan; lisensi komersial diperlukan untuk produksi.  
- **Apakah kompresi lossless?** Ya, kompresi bawaan Aspose.3D bersifat lossless untuk geometri dan tekstur.  
- **Berapa banyak pengurangan ukuran yang dapat saya harapkan?** Biasanya 30‑60 % tergantung pada kompleksitas adegan dan jumlah tekstur.

## Cara mengurangi ukuran file 3D dengan kompresi adegan
Muat adegan Anda, tambahkan geometri, lalu simpan menggunakan `AmfSaveOptions` dengan kompresi diaktifkan – langkah tunggal itu mengurangi ukuran file hingga 60 % sambil mempertahankan setiap vertex, material, dan tekstur. **`AmfSaveOptions` adalah kelas yang mengonfigurasi opsi penyimpanan format AMF, termasuk flag kompresi.** Aspose.3D memanfaatkan kompresi gaya gzip bawaan format AMF, mengemas geometri, material, dan tekstur ke dalam kontainer biner yang kompak tanpa kehilangan kualitas.

## Mengapa mengurangi ukuran file 3D?
Mengurangi ukuran file mempercepat unduhan, mengurangi biaya penyimpanan cloud, dan meningkatkan pemuatan runtime di browser atau mesin game. Dalam pengujian benchmark, Aspose.3D mengompres model 150 MB menjadi 58 MB, menghasilkan pengurangan 61 % dan waktu muat 2,3× lebih cepat pada koneksi tipikal 5 Mbps.

## Kapan harus memperkecil aset 3d?
Anda harus memperkecil aset 3d setiap kali menargetkan perangkat seluler, jaringan berbandwidth rendah, atau skenario apa pun di mana waktu unduh secara langsung memengaruhi kepuasan pengguna. Kompresi pada tahap awal juga mengurangi tekanan cache CDN, menjaga repositori kontrol versi tetap ringan, dan menurunkan konsumsi memori pada perangkat klien, yang terutama penting untuk aplikasi AR/VR dan simulasi waktu nyata.

## Impor paket
Add the required Aspose.3D classes to your Java source file:

```java
import com.aspose.threed.AmfSaveOptions;
import com.aspose.threed.Box;
import com.aspose.threed.Scene;
import com.aspose.threed.Transform;
import com.aspose.threed.Vector3;
```

## Panduan langkah‑demi‑langkah

### Langkah 1: siapkan proyek Java Anda
Buat proyek Java baru di IDE pilihan Anda dan tambahkan file JAR Aspose.3D ke classpath proyek. Ini memastikan kompiler dapat menemukan kelas yang diimpor.

### Langkah 2: inisialisasi adegan 3D baru
`Scene` adalah kontainer inti Aspose.3D yang menyimpan geometri, cahaya, kamera, dan hierarki untuk model 3‑D.  
Mulailah dengan membuat objek adegan kosong. Kelas `Scene` adalah kontainer untuk semua geometri, cahaya, kamera, dan hierarki.

### Langkah 3: buat adegan lengkap dengan kotak dan kompresi
Berikut adalah kode lengkap yang menggabungkan semua langkah – inisialisasi adegan, menambahkan geometri, dan menyimpan dengan kompresi:

```java
// The path to the documents directory.
String MyDir = "Your Document Directory";

Scene scene = new Scene();

Box box = new Box();
Transform tr = scene.getRootNode().createChildNode(box).getTransform();
tr.setScale(12, 12, 12);
tr.setTranslation(10, 0, 0);

tr = scene.getRootNode().createChildNode(box).getTransform();
tr.setScale(5, 5, 5);
tr.setEulerAngles(50, 10, 0);

AmfSaveOptions opt = new AmfSaveOptions();
opt.setEnableCompression(true);   // Turn on compression to shrink file size
scene.save(MyDir + "compressed_scene.amf", opt);
```

> **Pro tip:** Jika Anda perlu menyimpan versi asli yang tidak terkompresi untuk debugging, simpan salinan kedua dengan `setEnableCompression(false)`.

Ulangi langkah di atas untuk objek tambahan apa pun yang ingin Anda masukkan ke dalam adegan. Setiap objek akan disimpan dalam kontainer terkompresi yang sama, menjaga ukuran file secara keseluruhan tetap kecil.

## Tips dan praktik terbaik
- **Pilih format tekstur yang tepat** – PNG dan JPEG sudah terkompresi; hindari BMP bila memungkinkan.  
- **Gunakan kembali geometri** – Menginstansiasi mesh yang sama mengurangi data duplikat sebelum kompresi.  
- **Streaming adegan besar** – Aktifkan streaming dengan `AmfSaveOptions.setEnableStreaming(true)` untuk menghindari `OutOfMemoryError`.  
- **Validasi output** – Muat kembali file AMF yang disimpan ke dalam objek `Scene` untuk memastikan tidak ada yang hilang selama kompresi.

## Masalah umum & solusi
| Masalah | Penyebab | Solusi |
|---------|----------|--------|
| **File yang disimpan masih besar** | Kompresi dinonaktifkan atau menggunakan format yang tidak mendukungnya (mis., OBJ). | Pastikan `opt.setEnableCompression(true)` dan simpan sebagai **AMF**. |
| **Tekstur tidak muncul setelah dimuat** | Tekstur tidak di-embed; jalurnya eksternal. | Gunakan `scene.getRootNode().getMaterial().setTexture(...).setEmbed(true)`. |
| **OutOfMemoryError pada adegan besar** | Memuat seluruh adegan ke memori sebelum menyimpan. | Aktifkan mode streaming via `AmfSaveOptions.setEnableStreaming(true)`. |
