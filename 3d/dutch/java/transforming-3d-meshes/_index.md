## Hoe mesh transformeren in Java?
`Transform` applies a transformation matrix to the mesh's vertices.  
Load an existing mesh, apply scaling, rotation, or translation via the `Mesh` object's `Transform` method, and then save the result—this whole workflow can be performed in under 10 lines of code. The transformation matrix lets you combine multiple operations in a single call, ensuring high‑performance updates even on complex models.

## Hoe een Box omzetten naar Mesh?
`Box` represents a rectangular‑prism primitive, and `toMesh()` converts it into a mesh object.  
Instantiate a `Box` primitive, call its `toMesh()` method, and then export the mesh using `Scene.save()`. This conversion turns a simple geometric shape into a fully fledged mesh that you can further edit, texture, or animate. The process requires only a few API calls and works for all standard primitive types.
