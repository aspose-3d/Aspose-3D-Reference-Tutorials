# Создание 3d цилиндрических моделей

## Введение

Если вам когда‑нибудь нужно было **создавать 3d цилиндр** формы быстро и точно, вы попали в нужное место. В этом руководстве мы пройдемся по основным возможностям Aspose.3D for .NET, которые позволяют генерировать 3‑D сетки, менять ориентацию плоскости и даже линейно выдавливать 2‑D формы. К концу руководства вы будете уверенно моделировать цилиндры и другие примитивы, а также узнаете, где найти более глубокие примеры по каждой теме.

## Быстрые ответы
- **Что я могу создать?** 3‑D цилиндры, сетки и другие примитивные модели.  
- **Какой API используется?** Aspose.3D for .NET.  
- **Нужна ли лицензия?** Бесплатная пробная версия подходит для обучения; коммерческая лицензия требуется для продакшна.  
- **Поддерживаемые фреймворки?** .NET Framework 4.5+, .NET Core 3.1+, .NET 5/6+.  
- **Типичное время реализации?** Около 10‑15 минут для базового цилиндра.

## Что такое 3d цилиндр в Aspose.3D?

3d цилиндр — параметрическое тело, определяемое радиусом, высотой и необязательной сегментацией. Aspose.3D позволяет создать его одной строкой кода, автоматически генерируя подлежащую сетку.

## Почему стоит использовать Aspose.3D для создания 3d цилиндрических моделей?

- **Точность:** Библиотека автоматически вычисляет нормали вершин и UV‑развертку.  
- **Гибкость:** Комбинируйте цилиндры с другими примитивами, выдавливайте формы или меняйте ориентацию плоскости, не выходя из API.  
- **Производительность:** Aspose.3D может генерировать сетки для моделей объёмом 500 страниц менее чем за 2 секунды на типичном сервере, что делает её подходящей для рендеринга в реальном времени или пакетного экспорта в OBJ, STL или FBX.

## Как создать 3d цилиндр с пользовательскими размерами?

`Scene` представляет контейнер для всех узлов, источников света и камер в 3‑D документе. `Cylinder` — класс‑примитив, который строит цилиндрическую сетку из значений радиуса и высоты. Загрузите объект `Scene`, создайте примитив `Cylinder` с нужными радиусом и высотой и добавьте его в корневой узел сцены. Эта трёхшаговая схема создает полностью готовую сетку менее чем за дюжину строк кода C#. API также позволяет задавать количество сегментов по радиусу и высоте для контроля плотности сетки и более плавного рендеринга.

## Что такое класс Cylinder?

Класс `Cylinder` — встроенный примитив Aspose.3D, представляющий твёрдый цилиндр и автоматически создающий подлежащую треугольную сетку. Вы создаёте экземпляр, передавая радиус, высоту и необязательные количества сегментов, затем присоединяете его к узлу сцены для дальнейшего управления.

## Как изменить ориентацию плоскости для цилиндра?

Ориентацию плоскости меняют, применяя матрицу вращения или кватернион к узлу цилиндра. Поворот узла переориентирует всю сетку без пересоздания геометрии, сохраняя нормали вершин и UV‑координаты. Такой подход идеален, когда нужно выровнять несколько объектов вдоль пользовательской оси перед экспортом.

## Как экспортировать 3d цилиндрическую модель в STL?

`Scene.Save` записывает сцену в файл указанного формата. Вызовите метод `Scene.Save` с путём файла и перечислением `FileFormat.Stl`. Aspose.3D записывает бинарный STL‑файл, содержащий треугольную сетку цилиндра, готовый к 3D‑печати или дальнейшей обработке. Экспорт учитывает текущую иерархию трансформаций, поэтому любые вращения или масштабирования, которые вы применили, будут запечены в итоговом STL‑файле.

## Часто задаваемые вопросы

**В: Как создать цилиндр с пользовательским радиусом и высотой?**  
О: Создайте объект `Cylinder`, задайте его свойства `Radius` и `Height`, затем добавьте цилиндр в узел сцены. Сетка генерируется автоматически.

**В: Можно ли изменить ориентацию цилиндра после его создания?**  
О: Да. Примените трансформацию вращения к узлу цилиндра или используйте API ориентации плоскости для вращения всей иерархии сцены.

**В: В какие форматы файлов я могу экспортировать модель цилиндра?**  
О: Aspose.3D поддерживает OBJ, STL, FBX, GLTF и несколько других популярных 3D‑форматов для статических и анимированных сеток.

**В: Можно ли выдавить 2‑D круг в цилиндр?**  
О: Абсолютно. Используйте функцию линейного выдавливания на 2‑D круге; API сгенерирует твёрдую цилиндрическую сетку с корректной UV‑разверткой.

**В: Нужна ли выделенная видеокарта для работы с Aspose.3D?**  
О: Нет. Aspose.3D — чистая .NET‑библиотека и работает на любой машине, соответствующей требованиям .NET runtime; ускорение GPU опционально.
